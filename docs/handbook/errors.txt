Engine error codes

Engine errors appear as error codes. These can be caught and translated to text:

Error messages and code names
try {
    // Call the engine here.
} catch (const cambc::error& e) {
    std::cerr << e.message() << '\n';
}

auto code = cambc::error_code::api_not_in_vision;
auto text = cambc::to_string(code);

auto text_from_number = cambc::to_string(static_cast<cambc::error_code>(97));
