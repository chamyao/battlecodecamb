int32_t host_game_settings(Game_Settings *ptr);

WASM ABI: i32 game_settings(i32 ptr);

Read the immutable engine tuning (timers, ranges and memory capacities). This query does not require game initialization.

@param ptr: Address of a 120-byte Game_Settings record, aligned to 8 bytes. Memory: at least 120 bytes in exported linear memory; 8-byte alignment. Nonempty ranges must start at a positive address.
@return: i32 — 0 on success; an engine error code on failure, or -1 for invalid guest memory. Read outputs only on success.
