```python
@gene("s4", "how much closer a step brings me to the goals; while carrying gems never step next to an enemy champion")
def progress(t: Tile) -> Num:
    d = at(goal_field(), me().pos) - at(goal_field(), t)
    if gems() > 0 and d > 0:
        if any(dist(u.pos, t) <= 1 for u in enemies() if u.is_champion):
            return 0
    return d
```
