```python
@gene("s2", "where to walk: an altar with gems; home to shop with 150+ gold and no gems; else a living camp group")
def goals() -> Tiles:
    acc = near(tile(-5, -5), 0)
    if gems() > 0:
        for a in altars() - locked_altars():
            acc = acc | near(a, 1)
        return acc
    if gold() >= 150:
        return my_spawn()
    for g in range(num_groups()):
        if not group_respawning(g):
            acc = acc | group_tiles(g)
    return acc
```
