```python
@gene("s11", "turns to stand next to an altar we can tribute at (only enemy-locked altars are skipped, our own lock counts as open; 1000 if none)", parents=["s11"])
def altar_eta() -> Num:
    h = here()
    d = min((max(0, dist(h, a) - 1) for a in altars() if not lock_enemy(a)), default=-1)
    if d < 0:
        return 1000
    return eta(d, me().move_speed)
```
