```python
@gene('r5', 'recall with 5+ gems when hurt (threshold rises faster with carried gems: 0.67 at 10, 0.83 at 20) and nothing near, unless an altar is close enough to bank first (4 turns; 2 with a bag of 20+, a big bag is not risked on a hurt walk)')
def r_cashout() -> Bool:
    if at_spawn():
        return False
    g = gems()
    if g < 5:
        return False
    f = min(0.85, 0.5 + g / 60)
    if not hurt_below(f):
        return False
    if under_fire():
        return False
    return altar_eta() > (2 if g >= 20 else 4)
```
