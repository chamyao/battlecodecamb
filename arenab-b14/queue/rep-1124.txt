```python
@gene('r3', 'retreat on foot: under fire and below 30% health, or below 45% while carrying 10+ gems (a dead carrier hands its bag to the killer); not while an enemy champion in reach dies to our next basic attack (take the kill first)')
def r_run() -> Bool:
    if at_spawn():
        return False
    lim = 0.45 if gems() >= 10 else 0.3
    if not hurt_below(lim) or not under_fire():
        return False
    return not any(in_reach(u) and attack_damage(me(), u) >= u.health + shield(u) for u in enemies())
```
