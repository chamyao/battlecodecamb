```python
@gene('s4', "how much closer a step brings me to the goals (cached field); hurt and carrying gems (below 50%, or below 70% with 20+ gems), a step into an enemy champion's attack reach counts as no progress")
def progress(t: Tile) -> Num:
    d = at(GF, me().pos) - at(GF, t)
    if d > 0 and gems() > 0 and me().health_frac < (0.7 if gems() >= 20 else 0.5):
        if any(u.is_champion and dist(u.pos, t) <= max(u.attack_range, 1) for u in enemies()):
            return 0
    return d
```
