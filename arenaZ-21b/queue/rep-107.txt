@gene('s1', 'value of doing this option now; draft Marcella, Vendetta, Ryth; keep fighting camps until banking; flee then recall when hurt; recall to shop once 200 gold is saved; dash; chase weak enemy champions')
def score(o: Option) -> Num:
    if o.kind == PICK:
        return duel_order(o.champ)
    if o.kind == BUY:
        return strength_more(o.item)
    if o.kind == RECALL:
        if in_fight():
            return 0
        if me().health_frac < 0.35:
            return 90
        if gems() == 0 and gold() >= 200 and not can_shop() and at(GF, me().pos) >= 3:
            return 52 if me().health_frac < 0.85 or gold() >= 400 else 0
        return 0
    if o.kind == CAST:
        if slot_kind(o.slot) == AB_DASH:
            return dash_value(o.tile)
        return cast_value(o)
    if o.kind == ATTACK:
        if o.unit.is_champion:
            return 80 + (1 - o.unit.health_frac) * 10
        if not banking():
            return 60
        return 55 if is_awake(o.unit) else 0
    if o.kind == TRIBUTE:
        return 70
    if o.kind == MOVE:
        if me().health_frac < 0.35 and in_fight():
            g = threat_dist(o.tile) - threat_dist(me().pos)
            return 95 + g if g > 0 else 0
        if me().health_frac > 0.6:
            w = best(enemies(), lambda u: 0 - u.health_frac)
            if exists(w) and w.health_frac < 0.35 and dist(w.pos, me().pos) <= 5:
                return 70 if dist(o.tile, w.pos) < dist(me().pos, w.pos) else 0
        return 50 if progress(o.tile) > 0 else 0
    return 0

@gene("new", "worth of a purchase: the starter item first; with gold left over, the strongest strength shard", parents=["s1"])
def strength_more(i: Num) -> Num:
    if i == 6:
        return 100
    if item_strength(i) > 0 and item_cost(i) <= 30:
        return 90 + item_strength(i) * 0.1
    return 0

@gene("Z80a", "keep hunting camps while the bag is small: bank once carrying 16+ gems, when below half health, or near the end")
def banking() -> Bool:
    if gems() <= 0:
        return False
    if gems() >= 16 or me().health_frac < 0.5:
        return True
    return round() > 1900
