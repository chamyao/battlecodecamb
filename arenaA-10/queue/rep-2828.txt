```python
@gene("w6", "how much closer a step onto t brings me to GOAL (0: no walk this turn); turn-start field and blocks; below half health, never a step next to two or more enemy champions (a pinch)")
def step_gain(t: Tile) -> Num:
    if not OPEN or t in BLOCK:
        return 0
    if hurt_below(0.5) and count(dist(u.pos, t) <= 1 for u in enemies()) >= 2:
        return 0
    return at(FIELD, here()) - at(FIELD, t)
```
